# Frontend Fundamentals 모의고사

## Getting started

```sh
yarn dev
```

## 개선사항

### 1. 사용자가 조건을 입력할 때 숫자만 가능하게 TextFieldProps에 입력을 제한할 수 있는 type을 넣으면 좋을 것 같다.

### 2. 사용자가 찾고자하는 상품은 조건에만 맞는다면 연 이자율이 가장 높은 상품일 것이다. 상품 결과를 연 이자율 순으로 내림차순 정렬해서 보여주는 것도 괜찮을 것 같다.

### 3. 사용자가 조건을 입력할 때 한번에 조건값을 지울 수 있는 x 버튼이 TextField에 값이 있으면 가장 오른쪽에 노출되면 괜찮을 것 같다.
